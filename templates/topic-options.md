# 选题建议格式（第 2 步输出）

```markdown
## 选题方向（请选一个，也可以都不要，我们重新找）

### 1. 角度名（六个字以内）
**核心看点**：一句判断，不是描述话题。
**需要材料**：有 → …；没有 → 需要你补 …

### 2. 角度名
**核心看点**：…
**需要材料**：…

### 3. 角度名
**核心看点**：…
**需要材料**：…

---
我的倾向：第 N 个，因为…（只给依据，由你定）
```

## 写法要求

- 2–6 条，宁少勿同义。
- 每条核心看点必须含一个判断，能撑起一篇千字文，不是一句标题。
- 需要材料写清「有什么」和「缺什么」，缺的标出来，不要含糊成「建议补充素材」。
- 不写文章结构，不给段落提纲，那是第 4 步的事。
