# 文章思路单（第 4 步输出，用户确认后才能写初稿）

```markdown
## 文章思路单

**目标平台**：…（档位：…，段落上限 … 字，标题 … 个）
**核心观点**：一句话，能被读者复述出来。
**读者**：写给谁，他们卡在哪。
**切入**：从哪个具体场景 / 反例 / 问题进。

### 段落安排
1. 【现象】…
2. 【原因】…
3. 【例子】…
4. 【反例】…
5. 【判断】…
6. 【落地】…

### 材料对应
- 判断 2 用到：…（来自知识库 / 你口述 / 待补）
- 例子 3 用到：…

### 待确认
- …
```

## 检查五问（给用户看建议，不替他改）

1. 这篇文章真正想表达什么？
2. 核心观点是否清楚，能不能一句话说出来？
3. 各段之间有没有推进关系，还是只是并列？
4. 哪两段说的是同一件事，可以合并？
5. 哪一处最值得展开但现在太薄？

## 硬要求

- 每段标一个作用，只标一个。
- 需要小标题的平台，段落安排里就写出小标题草稿。
- 观点不能是常识复述；若确实只是整理，写明「这是整理稿」。
- 用户不改思路单，不进入第 5 步。
