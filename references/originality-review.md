# 原创审查：有他人素材时的硬门禁

用途：用户提供了别人的文章、图片、聊天记录、报告时读本文件。没有他人素材也要做一次轻量版（跳过第 4 条之后，只查是否在复述常识）。

原创的标准是用自己的思考重新完成一次表达。把别人的话换一套说法，达不到这个标准。判定只有一条：**读者能不能看出这篇文章的来源**。

## 执行步骤

1. **列素材清单**：哪些是事实来源（数据、事件、结论），哪些只是提供线索。
2. **抽事实卡**：时间、数字、机构、人名、事件经过、对方的核心结论。数字与单位原样保留，不改不凑。
3. **弃用原文结构**：标题、段落顺序、论证路径、例子顺序，一个都不沿用。原来的三段并列，就换成因果；原来的先现象后结论，就换成先反例后修正。
4. **重建切入点**：从自己的观察或经验里找一个具体入口，而不是复述对方的第一段。
5. **加自己的判断**：至少一处只属于你的解释、经验或反例，且不是常识复述。
6. **跑重合检测**：

```text
python scripts/originality_diff.py --draft <成稿> --source <素材1> [--source <素材2>]
```

默认连续 12 字判为痕迹。平台不能执行脚本时，用「连续 12 字人工比对」替代：把素材里的判断句和例子摘成清单，逐条在成稿里搜关键短语，命中就重写该段，并在审查记录里写「未跑脚本，人工比对」。

7. **人工读一遍**：找这几样残留——眼熟的句式、换过词的连续句、和原文一样的例子顺序、和原文一样的转折句。

## 七条不能做的事

1. 只取信息和事实，不沿用原文表达。
2. 不照搬标题、结构、段落顺序、论证方式、句式。
3. 不做同义词替换，不做逐段对应改写。
4. 从自己的观察出发，重新找切入点、重新排论述顺序。
5. 加入有依据的独立判断、实际经验或新解释。
6. 保留必要的事实和来源，不编造案例、数据、个人经历。
7. 完成后检查是否仍有原文表达痕迹，发现就重新组织。

## 判定三级

| 级别 | 判定条件（同时满足） | 处理 |
|---|---|---|
| 合格 | 无 12 字以上连续重合；结构与句式不逐段对应；至少一处独立判断 | 通过，记录到审查表 |
| 需重组 | 有少量重合或结构对应，但独立判断成立 | 只改有痕迹的段落：改论述顺序、换例子、换句式 |
| 退回重写 | 重合率高、逐段对应、或没有独立判断 | 不修修补补，重新搭思路后再写 |

脚本给的是数字，级别仍要结合结构判断：重合率低但逐段对应，也算不合格。

## 原创审查记录（交付时附上）

```text
素材来源：《…》（作者 / 链接 / 日期）
保留的事实：…
弃用的原文结构：标题 / 段序 / 例子 / 转折句（逐项写弃用了什么）
新的论述顺序：…
独立判断 / 经验：…（列出具体是哪几句）
重合检测：重合率 x.x%，最长重合 n 字，集中在【第几段】
判定：合格 / 需重组 / 退回重写
```

## 反例

- 「把原文每段的第一句换个说法」——仍是逐段对应，不合格。
- 「原文讲三个原因，我改成三点方法论」——结构没动，不合格。
- 「加了几句自己的感慨」——感慨不是判断，不合格。
- 「保留原文所有例子，只调换顺序」——例子是表达的一部分，不合格。
