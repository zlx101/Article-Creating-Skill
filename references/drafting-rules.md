# 打磨规则：内容整理 / 逻辑调整 / 语言打磨

用途：第 6 步读本文件。顺序不能换——先删，再顺，最后才是语言。跳过前两步直接润色，会留下逻辑断层和空段。

段落与句子的具体上限按 [platform-profiles.md](platform-profiles.md) 取，本文件给规则，不给数字。

## 一、内容整理（先删）

删这些：

- 口头语：然后、就是、那个、就是说、对吧、怎么说呢、其实吧
- 重复：同一意思说了两遍以上，留最具体的那句
- 铺垫：我简单说两句、说点自己的看法、可能不太成熟
- 自我复述：写完一段又把这段的意思总结一遍
- 无效过渡：接下来我想谈的第二个方面是…

修语病：

- 缺主语的长句，补主语或断成两句
- 半句话挂在那里的，补完或删掉
- 连续多个「的」连缀，拆开
- 一句话里套三层从句，拆成两句

**底线**：只删表达，不动观点。删完如果某个判断没了依据，把依据留着，删结论性重复。

## 二、逻辑调整（再顺）

1. 给每段标作用，只能是这六种之一：现象 / 原因 / 例子 / 反例 / 判断 / 落地。
2. 一段出现两个作用就拆段；一段哪个作用都不是就删。
3. 检查推进方向，常见四种骨架选一个：
   - 现象 → 为什么 → 怎么办 → 边界
   - 常见说法 → 它成立的条件 → 条件变化后 → 新判断
   - 我做了一件事 → 结果和预期不同 → 差在哪 → 后来怎么处理
   - 一个问题 → 三种解释 → 哪个解释站得住 → 我的结论
4. 相邻两段如果没有推进关系（只是并列举例），合并成一段或删掉弱的那段。
5. 需要小标题的平台，把每段的作用提炼成小标题；小标题要能单独看懂。
6. 衔接只补一句必要的话，写清因果或转折；不加「首先/其次/最后」「与此同时」「值得一提的是」。

## 三、语言打磨（最后）

- 句子按平台句长上限控制，超过就拆。
- 抽象词换成具体名词：不是「效率提升」，是「原来两天，现在半天」。
- 判断后面跟场景：谁、什么时候、做了什么、结果怎样。
- 数字保留原口径和单位，不估算、不四舍五入成好看的数字。
- 结尾落在一个具体动作、一个判断或一个待解决的问题，不写「希望这篇文章对你有帮助」。
- 开头两句话内出现具体的事，不写「在当今社会」「随着…的发展」。
- 加粗只标核心判断，密度按平台档；不要为了加粗而造句。

## 黑名单分级

**A 级（出现即改，属于明显 AI 腔）**

赋能、闭环、底层逻辑、颗粒度、抓手、护城河、降维打击、认知升级、顶层设计、生态位、组合拳、飞轮、心智、范式、链路、锚点、第一性原理、价值锚定、增量博弈

不得不说、值得深思、引起广泛讨论、在这个时代、让我们一起、本文将、综上所述、总的来说、希望这篇文章、干货满满、深度好文

**B 级（同篇出现两次以上就改）**

更重要的是、与此同时、换句话说、某种意义上、某种程度上、本质上、显然、事实上、可以说

**C 级（结构性 AI 腔，靠读）**

- 三段排比，每段句式一样
- 每段结尾都有一句总结性金句
- 大量「不是…而是…」句式反复出现
- 全篇没有具体的人、时间、地点、数字
