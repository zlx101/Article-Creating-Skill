# 写文规则（成稿正文硬约束）

适用范围：**成稿正文**。技能文档自身的标注写法不受此限。这份规则优先于文采偏好，与平台参数冲突时以更严的一条执行。

## 一、连接词：不用机械过渡

禁用：首先、其次、再次、最后、然后、接下来、另一方面、与此同时、综上所述、总的来说、总之。

这些词的共同问题是只标位置，不供给信息。读者看得到顺序，看不到推进。

换成能带信息的手法：

| 想表达 | 别写 | 换成 |
|---|---|---|
| 第一点 | 首先 | 先说最要紧的 / 最直接的一层 |
| 第二点 | 其次 | 还有一层 / 更麻烦的是 / 顺着往下说 |
| 顺承 | 然后 | 后来 / 三天后 / 接着我去查了 |
| 收尾 | 最后 | 说到底 / 现在的做法 / 我更愿意说 |
| 换角度 | 另一方面 | 换个位置看 / 从客户那边看 |
| 同时发生 | 与此同时 | 同一时间 / 差不多那几天 |
| 总结 | 综上所述 | 所以 / 我的结论只有一句 |

反例：首先，要明确目标；其次，要拆解任务；最后，要坚持执行。
正例：目标定错的时候，拆得越细越糟。我上周那份计划拆到二十七条，第二天方向就变了。

前者三段并列，读完一条也记不住。后者把顺序藏进因果里，读者跟着事走。

## 二、句式：长短交替，允许插入语

三条硬要求：

1. 不许连续出现三个以上短句（每句不足十二字）。
2. 不许三句以上同结构排比。三段开头都是「它需要」，就是排比。
3. 一段里至少有一处长短交错，靠逗号、括号或追问做出呼吸。

允许的插入语有三种：

- 括号补背景：这个配置我讲过四遍（当时还以为讲清楚了）。
- 逗号插入：客户在群里反馈的时候，我正在开会。
- 句中追问：他答了四十分钟，比我讲四遍都牢。为什么？因为是他自己走完的判断。

反例：它需要耐心，需要勇气，需要坚持，更需要对长期主义的信仰。
正例：这件事最难的地方在前三个月。没有任何反馈，你还要继续改。

## 三、数据和结论要落地

每出现一个数字或一句结论，后面补三件事里的至少一件：

- 口径：这个数怎么算的，含不含谁。
- 时间：哪一年的，变化发生在哪个月。
- 谁在观察：我算的、客户说的、还是表里查的。

反例：这套方法显著提升了团队效率。
正例：同样的需求，原来从提出到上线要九天，现在是四天。多出来那天没闲着，都用在验收上。这是我自己跟了三个月的数据，只统计我们组。

结论同样要落地。写完一句判断，接一个具体场景：谁、什么时候、做了什么、结果怎样。

只说这五个字很有效，等于没说。读者没法照着做，也没法反驳。

## 四、段落过渡：用追问或小结承接

合法过渡只有四种，都要带信息：

1. 追问：那问题出在哪？往下看一层。
2. 小结：这件事说明的东西，比看起来小。
3. 指代：上面那笔账，我一直算错。
4. 场景切换：真正难的是第二天。

反例：接下来我们来看第二个方面。
正例：第一晚我以为最难的是改配置。第二天才发现，难的是让他自己发现改错了。

## 五、禁用字符

正文里一个都不要出现：

| 字符 | 为什么禁 | 替代写法 |
|---|---|---|
| 左引号、右引号 | 装饰性太强，句句包词就是 AI 腔 | 直接引述，或改成陈述句 |
| 破折号 | 万能连接符，掩盖逻辑断层 | 逗号断开，或拆成两句 |
| 三个连字符 | 分割线，正文不需要 | 删掉，或改成小标题 |
| 大于号 | 引用块标记，公众号不支持 | 改成正文陈述 |
| 星号 | 列表符与单星号强调 | 改成句子，或删掉 |
| 连字符 | 列表符，及数字范围里的横线 | 范围写「到」或「至」 |

例外只有一处：`**加粗**` 是排版语法，成对出现时允许。单独的星号一律禁止。

数量与范围也别用横线。写成「三到五天」「八点到十点」，不要写成 3-5、8-10。

## 六、段落不超过两行

按手机阅读宽度估算，一行约二十五个汉字，两行就是五十字上限。这是一个估算值，不是精确像素。

平台不同，单行宽度不同，上限随之变化，取值见 [platform-profiles.md](platform-profiles.md)。

为什么卡这么短：手机上一屏只显示十来行，段落一长，读者看不见段与段之间的气口，划走的速度就快了。

短段落不等于把每句都写短。一段通常两到三句，其中一句可以带插入语长一些，前后各一句收住。

## 七、两行段落和句式层次怎么共存

这是本规则内部最容易顾此失彼的地方。做法有三条。

一是把长句拆开而不是写短句。原来一句四十八字的复合句，拆成两句各二十字，中间用逗号接上语气，还是一段话。

二是靠插入语做出层次，不靠从句嵌套。四十字以内放一个括号或一个逗号插入，句子就有起伏了。

三是用追问换行，不要用排比凑段。一段问一句、答一句，比一段堆三个并列短语更有推进。

反过来，为了压到五十字而把每句砍成八字，就变成连续短句，违反第二节。宁可让某一段略超两字，也不要写成电报体。

## 交付前自检

```text
python scripts/check_content.py 成稿.md --platform <档>
```

脚本会给出这些判定：禁用字符（FAIL）、机械连接词（FAIL）、段落超两行（超一成记 WARN，超四成记 FAIL）、连续短句与句式整齐（WARN）、加粗密度（WARN）。

脚本查不了两件事：句子是否真的在推进，数字是否真有来源。这两条仍要人读一遍。
