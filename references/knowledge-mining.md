# 调积累：检索知识库并判断材料能不能用

用途：第 3 步读本文件。目的是把用户已有的旧文、笔记、案例找出来当**依据**，不是拼成文章。

## 找什么

- 同主题或邻近主题的旧文（哪怕是三年前写的）
- 读书笔记、课程笔记里与本次角度相关的段落
- 项目复盘、实践记录、数据截图、聊天记录里的现场细节
- 零散想法（备忘录、朋友圈、语音备忘）

## 怎么找

1. 先确认位置：本机目录、笔记库、历史文章目录、agent 存储。用户说不出位置，就问「旧文一般放在哪个文件夹」。
2. 用选题里的 2–3 个核心词分别搜，不要只用整句。
3. 命中的先看标题和首段，判断是否同主题，再决定要不要细读。
4. 找到后摘出**具体片段**（含数字、时间、场景、结论），不要只记「写过类似的东西」。

## 判断可用性

三条都满足才算可用：

1. 有事实、细节或一手经验，不只是观点。
2. 与本次角度相关（能支撑或反驳本次的判断）。
3. 不是同一篇的重复投放。

可用性分三档，输出时标明：

- **可直接引用**：事实、数据、经历，有出处。
- **只能作背景**：观点相近但缺细节，只能帮你确认方向，不进正文。
- **不合适**：与本次判断冲突，或只有情绪没有内容。

## 怎么用

材料是论据，不是段落。用法只有三种：支撑一个判断、提供一个例子、构成一个反例。

不要做这几件事：把旧文段落粘进新文；把两篇旧文拼成一篇；为了用上材料而硬加一个不相关的段落。

## 输出格式

```text
找到的材料：
1. 【可直接引用】《旧文标题》(路径/日期) — 片段：… — 可支撑：…
2. 【只能作背景】… — 为什么不能直接用：…

不合适的：
- 《…》 — 原因：与本次判断冲突，需要你确认用哪个

缺口：
- 缺一线数据/案例/时间线，需要你补：…
```

## 没有找到时

直接说「这次没有检索到相关旧材料」，再给两条路：用户提供路径或口述一段经历；或者这次就只靠现有素材写，把范围收窄。

不要用「根据你以往的风格」这类话替代真实检索。
